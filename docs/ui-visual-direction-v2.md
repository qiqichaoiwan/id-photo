# 小七快照拍 UI 视觉统一方案 V2

日期：2026-10-31  
定位：基于用户提供的[证件照主流程设计图](ui-design-v1.png)，统一会员、结果页、工具页和套餐后台的视觉风格。本文和设计图是视觉方案，业务需求与状态规则以[需求汇总 V2](requirements-membership-v2.md)为准。

## 一、设计目标

以证件照工具为主，界面清晰、安静、容易操作。首页可以有少量亲切的插画；真正的照片预览应呈现真实照片和实际输出比例，不使用卡通人物代替用户照片。会员功能融入原有流程，用户在购买前能看懂价格、时长、免广告权益和续费方式。

- [会员状态页面](ui-membership-states-v2.png)：支付确认中、支付取消和会员到期。

图中的人物、有效期、订单和商品状态均为示意。支付成功以服务端确认发放权益为准；普通用户保存仍需观看完整激励广告。所有图是参考稿，实际页面文案和边界状态以需求文档为准。

## 三、视觉规范建议

以下是供后续实现使用的初始数值，可在真机上微调：

| 项目 | 建议 | 用途 |
| --- | --- | --- |
| 品牌色 | `#CC3D35` | 主要按钮、选中边框及少量强调；白色按钮文字应保持清晰。 |
| 页面背景 | `#F6F6F6` | 让白色卡片形成轻微层次。 |
| 卡片 | `#FFFFFF` | 主要内容容器，辅以细边框或轻阴影。 |
| 主要文字 | `#17191C` | 页面标题和关键内容。 |
| 次要文字 | `#666B73` | 提示、尺寸、说明文字，避免过浅而难以阅读。 |
| 分隔线 | `#E8EAED` | 列表和输入框边界。 |

- 字体和层级：页面标题约 18 px，区块标题约 16 px，正文约 15–16 px，辅助说明约 13–14 px；优先使用系统中文字体。不同宽度屏幕允许换行，不缩得难以阅读。
- 间距和圆角：以 375 px 宽度为参考，页面左右留约 16 px，卡片内部留约 16 px，区块之间保持清晰间隔；卡片圆角约 12 px，按钮圆角与原主流程一致。
- 操作：每页突出一个主要操作，触摸区域至少约 44 px 高。红色仅用于关键操作和选中状态；选中项同时使用边框或标记，不能只靠颜色区分。
- 导航：延续参考图的微信胶囊、顶部标题和底部导航；固定按钮为系统安全区域留出空间，避免遮住内容。
- 图标：统一使用线性图标，笔画和大小一致。会员可以用小型标识提示，不用大皇冠、大色块或夸张促销装饰。
- 图片：结果页优先突出照片本身，显示实际规格与背景色；工具状态或价格不覆盖照片主体。

## 四、关键页面规则

1. **会员中心**：三个套餐按 1 个月 ¥12、3 个月 ¥24、12 个月 ¥68 展示；同时说明单次购买、自然月、续费叠加与免广告权益。
2. **确认订单**：展示实际套餐、时长、金额和不自动续费说明；界面不展示未确认的优惠或额外会员权益。
3. **支付状态**：确认中提供查单入口并提示勿重复付款。取消、失败等状态使用同一套样式，文案和操作按服务端订单状态决定。
4. **普通用户与会员结果页**：保持相同的照片编辑布局，只在保存提示和按钮上体现广告或免广告区别；其他工具保存时也遵循同一权益判断。
5. **后台**：套餐表格与编辑表单采用相同的中性色、边框、字号和按钮风格。时长可输入自然月数，所有套餐固定包含免广告，微信商品和价格未核实前保留草稿状态。

## 五、实施注意

- 先把颜色、字体、间距、按钮、卡片和图标整理成统一设计令牌及组件，再逐页应用。
- 长文案、窄屏、微信胶囊位置、底部安全区域、广告异常和支付异常均应按真实状态适配，不能简单把视觉稿中的静态内容写死。
- 这是按参考图提出的视觉方向；是否符合目标用户偏好，应在可交互版本上收集用户反馈再调整。
