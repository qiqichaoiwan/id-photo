## 会员购买与退款规则

- 小程序以新鲜的 `wx.login` 凭据请求服务端创建订单，服务端生成虚拟支付签名。会员发放由服务端核对微信推送或查单后完成，不以客户端支付回调作为发放依据。
- 同一笔订单重复通知不会重复叠加会员时长；同一用户存在待确认订单时，相同套餐重试会沿用该订单。微信确认订单关闭前，其他套餐需等待订单核对。
- 月末按自然月计算：例如 1 月 31 日购买一个月，若当年 2 月没有 31 日，则到期为 2 月末对应时刻。到期按北京时间显示。
- 退款成功后先标记人工核对，不自动回收会员。管理员可在后台记录处理结论；只有管理员明确输入新的到期时间并确认时，系统才会修改会员到期时间，操作会记录审计信息。
- iPhone 用户向 Apple 申请退款时，系统默认建议同意退款，最终决定由 Apple 作出。

## 管理后台

公网地址：[https://idphoto-admin.ruize.eu.org/](https://idphoto-admin.ruize.eu.org/)。先使用已授权管理员邮箱接收 Cloudflare 一次性验证码，再以用户名 `admin` 和此前设置的后台密码登录；Cloudflare 会话为 6 小时。本机仍可通过 `http://127.0.0.1:8091/` 访问。后台进程仅监听本机，公网访问经过独立的 Cloudflare Access 策略以及 Tunnel 对 Access JWT 的校验。

- **运营概览**：查看用户、有效会员、已发放订单和待核对事件数量，以及本机服务和公网连接情况。订单数量不是最终结算收入。
- **服务监控**：从正在运行的本机照片 API 获取服务状态，同时检查本机能否通过 `photo.ruize.eu.org` 访问服务，以及支付消息接收端口是否监听。公网检查失败只能说明当前机器无法通过该域名连接，不能单独确定是本机网络、Cloudflare Tunnel 还是服务故障；端口监听正常也不能证明微信回调一定送达。接口统计仅记录固定接口、HTTP 状态分类和耗时，不包含图片、OpenID、令牌或请求内容；统计从启用后开始，队列繁忙或服务停止时少量记录可能丢失，有新请求时会清理超过 30 天的记录。
- **用户与会员**：使用匿名编号查看会员有效期、关联订单和最近 100 条权益流水；管理员可以填写原因并按自然月延长会员或指定到期时间。修改前会核对当前到期时间，防止覆盖并发续费；操作留有审计记录，不会伪造支付订单。
- **会员套餐**：创建、编辑、排序和归档套餐；微信商品发布后，核对商品 ID 和价格才能上架。套餐管理本身不会开启正式收款。
- **订单与退款**：按订单号、状态、北京时间和待核对标记筛选并分页，查看订单详情、权益发放及支付事件；微信查单沿用原有支付验证和幂等发放流程。退款先人工核对；如需调整会员时间，先读取并核对当前到期时间，再填写新的时间。其他待处理事件可记录人工核查结论。未匹配退款必须先根据微信退款单号、微信订单号和商户订单号核对本地订单。当前订单数据未保存操作系统渠道，后台不提供 iOS/Android 筛选；财务结算以微信后台账单为准。
- **操作日志与系统设置**：查看管理员操作记录；可设置后台概览和服务状态自动刷新间隔、列表每页数量。正式购买开关仍由服务端环境配置控制，不在后台提供开关。

2026-10-31 后台升级和开启现网支付前均已使用 SQLite 在线备份会员数据库及配套身份密钥，支付启用前备份位于 `~/Library/Application Support/XiaoqiPhoto/backups/20261031-130309-payment-enable/`。该目录包含敏感身份密钥，需限制访问并与数据库一起安全保存。恢复时应先停止相关服务，再将同一份备份中的数据库和身份密钥配套恢复；恢复前还需备份当时的数据。

## 运行环境与备份

- 小程序 API：`127.0.0.1:8080`；消息推送：`127.0.0.1:8092`；临时沙箱 API：`127.0.0.1:8093`。其中 8091、8092、8093 均只绑定本机。
- Cloudflare Tunnel 在原有图片服务规则前增加了支付回调与沙箱路径，并通过单独域名转发管理后台；原有照片 API 与支付回调规则保持独立。增加后台入口前的配置备份为 `~/.cloudflared/config.yml.backup-20261031-134441`，恢复配置前应先备份当前文件，再逐个重启两个 Tunnel 进程。
- 真实会员数据库是后端 `.miniapp_data/membership.sqlite3`，与 `.miniapp_data/identity.key` 必须作为一组妥善备份；丢失身份密钥将无法恢复会员用户与微信账号的对应关系。使用数据库安全备份方式，避免只复制正在写入的文件。
- `.env.miniapp`、`.env.miniapp.payment` 和 `.env.miniapp.sandbox` 含密钥，均应限制访问、妥善备份，不能提交仓库或发送到聊天。`.env.miniapp.admin` 保存后台公网主机名。现网密钥通过 `setup_payment_secrets.py` 在本机输入；沙箱密钥通过 `setup_payment_sandbox.py` 单独输入。
- 这是一台本机服务：Mac、网络或 Cloudflare Tunnel 离线时，查单和推送会受影响。正式运营需要确保持续在线、备份和告警。
