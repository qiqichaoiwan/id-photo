## 会员购买与退款规则

- 小程序以新鲜的 `wx.login` 凭据请求服务端创建订单，服务端生成虚拟支付签名。会员发放由服务端核对微信推送或查单后完成，不以客户端支付回调作为发放依据。
- 同一笔订单重复通知不会重复叠加会员时长；同一用户存在待确认订单时，相同套餐重试会沿用该订单。微信确认订单关闭前，其他套餐需等待订单核对。
- 月末按自然月计算：例如 1 月 31 日购买一个月，若当年 2 月没有 31 日，则到期为 2 月末对应时刻。到期按北京时间显示。
- 退款成功后先标记人工核对，不自动回收会员。管理员可在后台记录处理结论；只有管理员明确输入新的到期时间并确认时，系统才会修改会员到期时间，操作会记录审计信息。
- iPhone 用户向 Apple 申请退款时，系统默认建议同意退款，最终决定由 Apple 作出。

## 管理后台

访问 `http://127.0.0.1:8091/`，用户名 `admin`，密码使用此前本机设置的管理员密码。后台仅监听本机，可管理套餐、查看订单、向微信查单和核对退款。人工处理未匹配的退款前，应先根据微信退款单号、微信订单号和商户订单号核对本地订单。

后台、图片 API 和推送服务均由本机 LaunchAgent 运行。手动启动后台的命令：

```sh
cd /Users/qiqi/HivisionIDPhotos
./start_membership_admin.sh
```

## 运行环境与备份

- 小程序 API：`127.0.0.1:8080`；消息推送：`127.0.0.1:8092`；临时沙箱 API：`127.0.0.1:8093`。其中 8091、8092、8093 均只绑定本机。
- Cloudflare Tunnel 在原有图片服务规则前增加了支付回调与沙箱路径；原配置备份为 `/Users/qiqi/.cloudflared/config.before-idphoto-payment.yml`。
- 真实会员数据库是后端 `.miniapp_data/membership.sqlite3`，与 `.miniapp_data/identity.key` 必须作为一组妥善备份；丢失身份密钥将无法恢复会员用户与微信账号的对应关系。使用数据库安全备份方式，避免只复制正在写入的文件。
- `.env.miniapp`、`.env.miniapp.payment` 和 `.env.miniapp.sandbox` 含密钥，均应限制访问、妥善备份，不能提交仓库或发送到聊天。现网密钥通过 `setup_payment_secrets.py` 在本机输入；沙箱密钥通过 `setup_payment_sandbox.py` 单独输入。
- 这是一台本机服务：Mac、网络或 Cloudflare Tunnel 离线时，查单和推送会受影响。正式运营需要确保持续在线、备份和告警。
